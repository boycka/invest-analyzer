Informations financières

Le budget est obligatoire. Le budget doit être supérieur à 1 000 DH.
La source de financement est obligatoire.
Le chiffre d'affaires est obligatoire. Le montant doit être supérieur ou égal à 0.
Le retour sur investissement est obligatoire. Le retour sur investissement doit être supérieur à 1 mois.
